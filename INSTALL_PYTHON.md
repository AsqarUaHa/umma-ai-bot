# Установка Python для UMMA AI Bot

## Проблема

У вас установлен Python через Microsoft Store, который не работает корректно с виртуальными окружениями.

## Решение: Установите полную версию Python

### Шаг 1: Удалите Python из Microsoft Store (опционально)

1. Откройте "Параметры" → "Приложения"
2. Найдите "Python" и удалите

### Шаг 2: Скачайте официальный Python

1. Перейдите на https://www.python.org/downloads/
2. Скачайте **Python 3.11.9** (или новее)
3. Запустите установщик

### Шаг 3: Важные настройки при установке

**ОБЯЗАТЕЛЬНО отметьте:**
- ✅ **"Add Python to PATH"** (внизу окна установщика)
- ✅ **"Install for all users"** (если есть опция)

Нажмите "Install Now"

### Шаг 4: Проверка установки

1. Откройте **новое** окно командной строки (cmd)
2. Выполните:
   ```
   python --version
   ```
3. Должно показать: `Python 3.11.9` (или вашу версию)

### Шаг 5: Запустите бота

После установки Python:
1. Дважды кликните `run.bat`
2. Или запустите `run.ps1` через PowerShell

## Альтернатива: Ручной запуск

Если не хотите переустанавливать Python, можете попробовать запустить через py launcher:

```cmd
cd C:\scripts\umma-ai-bot
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
